## Installation

Copier le dossier dans `~/.claude/skills/naim-precision-radar/` (ou `.claude/skills/naim-precision-radar/` d'un projet), en gardant le fichier `SKILL.md` a la racine du dossier.

Le skill s'active tout seul quand la demande correspond a sa description (premier bloc de `SKILL.md`).
